개인정보 처리방침

Swaya는 사용자의 미디어 컬렉션을 개인 Windows PC에 안전하게 보관하도록 설계되었습니다.

1. 데스크톱 애플리케이션 (Windows용 Swaya)

로컬 동영상, 포토 갤러리, 즐겨찾기 목록, Finish 기록 및 개인 통계는 Windows PC에 직접 유지됩니다. Swaya는 사용자의 로컬 파일을 업로드하거나 판매하지 않습니다. 온라인 요청은 라이선스 인증, 앱 업데이트, 예고편 재생, 온라인 이미지 불러오기 또는 친구 기능 사용 시에만 발생합니다.

2. 라이선스 인증 및 결제

멤버십 및 Founding Lifetime Pass 결제는 Patreon에서 처리됩니다. 라이선스 확인 과정에서는 활성 키나 등급을 검증하는 데 필요한 최소한의 정보만 교환합니다.

3. 본 웹사이트 (swaya.xyz)

swaya.xyz는 분석 추적기나 광고 쿠키가 없는 정적 웹사이트입니다. 언어를 선택하면 브라우저의 localStorage(swaya_web_locale)에 선택한 언어 코드만 저장됩니다.

4. 문의

개인정보 관련 문의나 지원 요청은 support@swaya.xyz 또는 Discord 커뮤니티로 연락해 주세요.
