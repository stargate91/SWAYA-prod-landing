변경 내역 및 업데이트

Windows 10 및 11 환경을 위해 성능, 링크 가져오기, 파일 정리 및 안정성을 지속적으로 개선하고 있습니다.

v1.1.26

최신
2026-11-26
  • 정리기 설정에 선택 사항인 '단독 비디오 폴더'를 추가하여 개인 클립과 비디오 모드 항목을 카탈로그 장면과 분리된 별도 폴더나 드라이브로 정리할 수 있습니다
  • 정리기의 '폴더 스캔' 분할 메뉴에 '라이브러리 폴더 다시 스캔' 및 '미일치 항목 다시 매칭'(선택 항목 일괄 다시 매칭 포함) 기능을 추가했습니다
  • 파일별 스캔 제외 사유와 매칭 추적 내역을 기록하는 전용 scan_resolve.log 파일과 기록/실행 취소 페이지의 '로그 열기' 버튼을 추가했습니다

v1.1.25

Patreon 활성화 수정
2026-11-26
  • 초기 설정 마법사에서 Patreon 활성화가 누락되던 문제를 수정하여 브라우저에서 Open SWAYA 클릭 시 즉시 잠금 해제됩니다
  • 콜드 스타트 중 백엔드 준비 전에 전달된 swaya:// 활성화 링크가 유실되지 않도록 대기 처리를 추가했습니다
  • Windows 설치 프로그램에 swaya:// 프로토콜 핸들러를 등록하고 수동 활성화 링크 대체 입력을 지원합니다

v1.1.24

장면 배경 및 구조 정리
2026-11-25
  • 장면 상세 페이지의 적응형 배경 쇼케이스 규칙이 이제 단독 비디오(video)에만 적용되어 카탈로그 장면은 항상 전체 화면 커버로 표시됩니다
  • OSHash 및 이미지 지각 해시(pHash) 유틸리티를 공용 백엔드 인프라 모듈로 통합해 갤러리, 링크 수집, 유지보수, 지문 매칭 및 스캐너 전반에 적용했습니다
  • 명시적 모듈 임포트와 패키지 내보내기 정리를 통해 백엔드 시작 및 도메인 경계를 깔끔하게 개선했습니다

v1.1.23

오버레이 및 안정성
2026-11-25
  • 모달, 드로어, 라이트박스(FocusScope 포함), 드롭다운, 분할 버튼, 컨텍스트 메뉴, 팝오버, 툴팁 전반의 통합 오버레이 스택과 최상위 닫기 순서 적용
  • 플레이어 종료 오버레이 상태 동기화 정리 및 파일 정리기 기록 카드의 레이아웃 흔들림 없는 버튼 크기 고정, UI 포커스·스타일 다듬기
  • 아트워크 정합성, 갤러리 라우터, DB 유지보수 및 링크 수집 모듈 전반의 백엔드 타입 안정성, FastAPI 의존성 및 린터 보강

v1.1.22

삭제 UX 및 캐시
2026-11-24
  • 갤러리 3가지 삭제 모드(라이브러리에서 제거, 앨범만 해제, 휴지통/영구 삭제)와 라이트박스 및 일괄 작업에서 라이브러리 vs 디스크/휴지통 사진 삭제 선택 대화상자 추가(관리 파일·원본 경로 파일 모두 지원)
  • 세로형·저해상도 커버를 위한 주변 블러 효과 기반 장면 상세 히어로 카드 도입, 포스터 이미지 디코딩 부드러움 개선, 시네마 카탈로그(F10) 단축키 안내 및 라이브러리/정리기 제어 UI 간소화
  • Electron IPC 기반 창 간 쿼리 캐시 동기화, 자동 롤백을 지원하는 낙관적 UI 업데이트 및 범위 지정 캐시 무효화로 깜빡임 없는 빠른 반응성 구현

v1.1.19

미디어 및 재생
2026-11-24
  • 델타 동기화 시 원본에서 삭제된 아트워크를 정리하면서 사용자 업로드·로컬 캐시는 보존하고, 확인된 404/410 원격 이미지를 UI에서 자동 복구
  • 병렬 시작 초기화, 적응형 IPC 폴링 및 단일 탐색 이어보기로 로컬 MPV 재생 시작 속도 향상
  • RedGIFs 정적 이미지, 다중 이미지 갤러리 및 reddit.com/media 뷰어 링크를 동영상이 아닌 사진으로 정확히 분류

v1.1.18

코어 및 오프라인
2026-11-24
  • FansDB 속도 제한 시 반환되는 임시 SVG 이미지를 Electron에서 차단해 캐시 오염을 방지하고, 호스트별 동시성 제한과 카드 썸네일 자동 재시도를 추가
  • networkMode always 적용으로 오프라인 상태에서도 로컬 백엔드 API 조회 및 변경 요청이 멈추지 않도록 개선
  • Link Grabber 크롤러/수집기, 갤러리 가져오기, 소셜 동기화, 트레일러 프록시 및 파일 정리기 청크 프리로딩 모듈화 및 tasks 순환 임포트 수정

v1.1.17

UI 및 수정
2026-11-23
  • SFW 블러, 링크 그래버, 시네마 카탈로그 위장 전환 버튼의 타이틀바 도구 스타일 및 아이콘 정렬 통합

v1.1.16

안정성 패치
2026-11-23
  • 카드, 모달, 다운로드, 설정, 입력 폼에서 실수로 두 번 클릭해 중복 요청되는 문제를 막는 액션 잠금 적용
  • Electron 및 백엔드 경로 설정 해석, 트레이/플레이어 수명 주기, 업데이터 오류 표시 개선
  • 카탈로그 동기화, 파일 정리기 및 UI 훅 안정성 향상 및 코드 정리

v1.1.15

주요 업데이트

  • Coomer, Bunkr, Lmlib 백그라운드 전체 페이지 수집, 중복 제거 및 취소 기능 추가
  • 갤러리 중복 감지 원클릭 전환, Ctrl+Enter 단축키 및 12개 언어 현지화 적용
