更新履歴・アップデート

Windows 10 / 11 向けにパフォーマンス、リンク取得、ファイル整理、安定性を継続的に強化しています。

v1.1.24

最新
2026-11-25
  • シーン詳細ページにおけるアダプティブ背景表示ルールを単独動画（video）のみに限定し、カタログシーンが常に全面カバー表示されるように修正しました
  • OSHash および画像の知覚ハッシュ（pHash）ユーティリティをバックエンドの共通インフラモジュールへ統合し、ギャラリー・リンク取得・メンテナンス・指紋照合・スキャナーで共有するようにしました
  • 明示的なモジュールインポートとパッケージエクスポートの整理により、バックエンドの起動構成とモジュール境界を簡素化しました

v1.1.23

オーバーレイと安定性
2026-11-25
  • モーダル、ドロワー、ライトボックス（FocusScope 対応）、ドロップダウン、分割ボタン、コンテキストメニュー、ポップオーバー、ツールチップのオーバーレイ階層スタックと最前面クローズ順序を統一
  • プレーヤー終了オーバーレイの状態同期を整理し、オーガナイザー履歴カードのアクションボタンのサイズずれを解消、あわせてフォーカスと UI スタイルを調整
  • アートワーク整合性チェック、ギャラリー API、DB メンテナンス、リンク取得サービス全体でバックエンドの型安全性・FastAPI 依存関係・リンター対応を強化

v1.1.22

削除UX＆キャッシュ
2026-11-24
  • ギャラリーの3モード削除（ライブラリから削除・アルバムのみ解除・ゴミ箱/完全削除）と、ライトボックスおよび一括操作でのライブラリ削除／ディスク・ゴミ箱削除の明確な選択ダイアログを追加（管理ファイル・既存パス両対応）
  • 縦長や低解像度のカバー向けに背景ブラー付きのシーン詳細ヒーローカードを導入し、ポスター画像のデコード滑らかさ、シネマカタログ（F10）ショートカット案内、ライブラリ／オーガナイザー操作性を改善
  • Electron IPC によるウィンドウ間のクエリキャッシュ同期、自動ロールバック付きの楽観的 UI 更新、および範囲を絞ったキャッシュ無効化により、ちらつきのない高速なレスポンスを実現

v1.1.19

メディア＆再生
2026-11-24
  • デルタ同期時に削除済みカタログ画像を整理しつつカスタム画像とローカルキャッシュを保護し、確認済みの404/410リモート画像をUI上で自動修復
  • 並列起動初期化・適応型IPCポーリング・重複シーク排除によりローカルMPV再生の立ち上がりを高速化
  • RedGIFsの静止画・複数画像ギャラリーおよび reddit.com/media 画像ビューアリンクを動画ではなく写真として正しく判定

v1.1.18

コア＆オフライン
2026-11-24
  • FansDB のレート制限時に返るプレースホルダー SVG を Electron 側で遮断してキャッシュ汚染を防ぎ、ホスト別の同時接続制限とサムネイル自動リトライを追加
  • networkMode always によりオフライン環境でもローカルバックエンドへの API クエリと変更処理が停止しないよう改善
  • Link Grabber、ギャラリー取込、ソーシャル同期、予告編プロキシ、オーガナイザーの分割一括読込をモジュール化し、tasks の循環インポートを修正

v1.1.17

UI＆修正
2026-11-23
  • タイトルバーのツールボタン（SFWぼかし、Link Grabber、シネマカタログ偽装切替）のスタイルとアイコン配置を統一

v1.1.16

安定性パッチ
2026-11-23
  • カード・モーダル・ダウンロード・設定・フォームでの誤ダブルクリックを防ぐアクションロックを実装
  • Electron とバックエンドのパス解決、トレイ/プレーヤー制御、アップデーターのエラー表示を刷新
  • カタログ同期・オーガナイザー・UI フックの安定性向上とコード整理

v1.1.15

大型アップデート
2026-11-22
  • URL一括取り込みで写真・動画統合インポートと2カラム画面に対応
  • Coomer / Bunkr / Lmlib のバックグラウンド全ページ巡回（重複除去・キャンセル対応）を追加
  • ギャラリー重複検出＆1クリック切替、Ctrl+Enter 送信、12言語ローカライズを実装

v1.1.10

インストーラー＆修正
2026-11-18
  • スクロール位置復元、リモート予告編の再生安定性、更新後の再起動処理を改善
  • 12言語の翻訳拡充と詳細ページ・フィルタUIのブラッシュアップ

v1.1.0

初回リリース
2026-10-01
  • オフライン統合カタログ、高機能内蔵プレーヤー、フローティング PiP を備えた Windows 10/11 初回版を公開
  • 自動シーン照合、1クリック取り消し対応の一括整理、F10 偽装モード、'B' ソフトぼかしを搭載
