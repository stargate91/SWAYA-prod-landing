常见问题解答

关于隐私保护、视频与照片支持、电脑要求及授权的清晰说明。

使用 Swaya 需要联网吗？

你的视频、照片图库、收藏列表、Finish 记录以及个人统计数据都保存在你的 Windows 电脑本地，离线即可使用。仅在激活授权、获取更新、播放预告片、加载在线封面图片以及使用 好友功能时需要联网。

Swaya 与 Stash 等浏览器整理工具有何不同？

Swaya 是真正的 Windows 桌面应用，安装打开就能用，无需搭建本地服务器或借助浏览器窗口。内置即用目录、支持一键撤销的自动整理、悬浮小窗播放（PiP）、照片图库、F10 一键伪装以及更多实用功能。

Patreon 订阅和 Founding Lifetime Pass 如何运作？

Swaya 是一款付费 Windows 应用。在 Patreon 选择 Member（€8/月）、VIP（€15/月）或 Executive（€25/月）即可解锁完整功能、持续更新以及最多 3 台电脑使用。限量 50 份的 Founding Lifetime Pass（€97 买断）可终身用于最多 3 台电脑，密钥会在购买后尽快通过 Patreon 私信发送（通常很快，最多几小时内）。

F10 一键隐藏和 'B' 键模糊怎么用？

按下 F10 会立刻静音并切换到简洁伪装界面；浏览时按 'B' 键可开启柔和模糊效果。

Swaya 支持哪些视频、图片文件格式和编码？

Swaya 内置播放器原生支持几乎所有主流视频格式（MP4、MKV、WebM、MOV、AVI、WMV、FLV、M4V），支持 H.264、HEVC (H.265)、AV1 与 VP9 硬件加速解码（最高 4K/60fps）以及悬浮画中画 (PiP) 小窗。图库相册支持 JPG/JPEG、PNG、WebP、GIF 和 AVIF 格式。

自动文件整理是如何工作的？一键撤销对我的本地文件安全吗？

将杂乱文件夹拖入整理器后，Swaya 会在修改硬盘文件前完整预览匹配到的标题、演员、片商和封面。整理过程绝不会删除任何媒体文件，且每次批量操作都会记录日志，随时可一键将文件名和文件夹结构恢复至原始状态。

内置的链接导入器 (Link Importer) 支持哪些网站？

内置 Link Grabber 支持从 Reddit、RedGIFs、Coomer、Bunkr、Lmlib 等 25+ 个站点直接抓取视频、流媒体和多页写真图库到本地媒体库，并带有自动合并相册与重复检测功能。

内置目录能识别哪些类型的作品（片商、OnlyFans、JAV、PMV）？

Swaya 覆盖主流成人片商、OnlyFans 及独立创作者、JAV 番号与演员作品以及 PMV 合集。每个演员档案自动关联曾用名、合作演员与完整作品集；你也可以为个人视频自由添加自定义标签和封面。

PIN 码锁、自动伪装和可选的好友模式如何保护我的隐私？

除了 F10 一秒静音切换伪装界面和 B 键封面模糊外，你还可以设置 4–6 位 PIN 码锁定应用，或开启离开电脑时的闲置自动伪装。好友模式默认完全关闭，无公开搜索目录，仅限私密好友码互加，且绝不会上传你的本地视频或观看历史。

我的 Windows 电脑能流畅运行 Swaya 吗？

只要你的电脑运行 64 位 Windows 10 或 11，配备双核 CPU、4 GB 内存及 20 GB 可用空间即可流畅运行。对于大型媒体库和 4K HEVC 视频，推荐使用 8 GB+ 内存和 SSD 固态硬盘。Swaya 专为 Windows 10/11 打造（无 macOS、Linux 或手机版）。

一个授权可以在几台电脑上使用？更换新电脑时可以转移吗？

所有 Patreon 订阅档位（Member、VIP、Executive）及创始终身通行证（Founding Lifetime Pass）均支持在最多 3 台个人 Windows 电脑上同时激活，更换电脑时可轻松转移设备绑定。

Patreon 账单足够私密吗？如何取消订阅或获取更新？

所有付款均由 Patreon 处理，银行账单上仅显示 Patreon，绝不会出现软件名称或敏感词。按月订阅可随时在 Patreon 一键取消，无任何捆绑；Windows 新版本可通过应用内更新器直接升级。
