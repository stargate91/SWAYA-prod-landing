Политика конфиденциальности

Swaya создан так, чтобы ваша личная медиаколлекция оставалась в безопасности на вашем ПК с Windows.

1. Десктопное приложение (Swaya для Windows)

Ваша локальная коллекция видео, фотогалереи, списки избранного, история Finish и личная статистика хранятся и работают прямо на вашем ПК. Swaya не загружает и не продаёт ваши локальные файлы. Сетевые запросы выполняются только для онлайн-функций: активации лицензии, обновлений, просмотра трейлеров, загрузки онлайн-обложек или функции «Друзья».

2. Лицензирование и оплата

Подписки и Founding Lifetime Pass оформляются через Patreon. Проверка лицензии передаёт только минимальные данные, необходимые для подтверждения ключа или тарифа.

3. Этот сайт (swaya.xyz)

swaya.xyz - статический сайт без аналитических трекеров и рекламных cookie. При смене языка в localStorage браузера сохраняется только выбранный код языка (swaya_web_locale).

4. Контакты

По вопросам приватности или поддержки пишите на support@swaya.xyz или обращайтесь в наш Discord.
